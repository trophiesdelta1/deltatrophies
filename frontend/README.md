# Delta Trophies frontend

React and Vite client for the Delta Industries catalogue.

## Commands

- `npm run dev` — start the local Vite server
- `npm run lint` — run ESLint
- `npm run build` — create a production build in `dist`
- `npm run preview` — serve the production build locally
- `npm run check` — run lint and production build together

Copy `.env.example` to `.env` and set `VITE_API_URL` to the backend origin, without `/api` or a trailing slash. See the repository root README for full setup and deployment instructions.
